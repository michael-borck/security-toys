Security Toys — small pages that break a misconception

Each one is a single self-contained page built to kill one specific wrong idea that slides reliably fail to kill. No install, no account, no network. Save the page and it still works. Part of the Assume-Breach series.

Crack Time

Kills: “complexity is what matters”. Time-to-crack is length × algorithm × work factor — and two of those three are the site’s decision, not yours.

House rules

  • One file. No CDN, no fonts, no fetch — runs from a USB stick, uploads to an LMS as a single file.
  • One idea. If it needs a tutorial, it’s too big.
  • Ninety seconds. Playable from cold by someone who read no instructions.
  • A “wait, what?” moment. Named in every spec. If a build doesn’t produce it, it isn’t finished.
  • Nothing leaves the page. No storage, no analytics, no backend, anywhere in this collection.
